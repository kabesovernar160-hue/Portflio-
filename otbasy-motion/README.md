# Отбасы — motion-ролик

22-секундный 3D motion-ролик об идее Отбасы банка (система жилищных строительных сбережений в Казахстане):
шанырак-солнце → монета → накопления → премия государства до 20 % в год → ипотека → свой дом → посёлок.

**Готовый файл:** `otbasy-motion.mp4` — 1920×1080, 60 fps, H.264 (yuv420p), звук AAC.

Ролик неофициальный: логотип и фирменный стиль банка не используются, в финальном кадре стоит дисклеймер.
Конкретные ставки намеренно не названы — они зависят от программы и меняются; из цифр только «до 20 % в год» (премия государства).

## Как устроено

| Файл | Что делает |
|---|---|
| `main.js` | Сцена на Three.js с детерминированным таймлайном: `window.renderAt(t)` рисует кадр для времени `t`. Буквы — настоящая экструзия из шрифта Inter (opentype.js). Motion blur — усреднение 3 субкадров, DOF — свой лёгкий проход по глубине. |
| `render.mjs` | Покадровый рендер через Playwright/Chromium (`stills`, `frames`, `events`). |
| `audio.py` | Музыка (домбра в «скачущем» ритме, пэд, бас, ритм) и звуковой дизайн, синтез на numpy. Время событий берёт из `events.json`, который выгружает сама сцена, поэтому звук и картинка идут по одним таймкодам. |
| `build.sh` | Полная сборка: события → звук → 1320 кадров → MP4. |

## Пересборка

```bash
npm install          # three, opentype.js
./build.sh           # ~40 минут на CPU (программный WebGL)
```

Нужны Node.js с Playwright + Chromium, Python 3 с numpy и FFmpeg.
Быстрая проверка отдельных кадров: `node render.mjs stills 4.1,9.5,21.5` → папка `probe/`.
